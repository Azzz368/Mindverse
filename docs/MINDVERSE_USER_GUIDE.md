# Mindverse 用户使用指南

## 1. Mindverse 是什么

Mindverse 是一个节点式多模态创作空间。你可以把文字、图片、视频、音频和分镜放在同一张无限画布上，通过连接线把一个节点的结果传给下一个节点。

例如：

```text
故事想法 → 剧本 → 分镜 → 图片 → 视频 → 抽取尾帧 → 下一个视频
```

也可以：

```text
人物图片 + 配音 → 数字人视频 → 视频剪辑 → 最终输出
```

不同模型可能产生真实费用。运行节点前请确认模型、素材、时长和输入数量。

## 2. 注册与登录

### 2.1 注册

访问 `/register`，填写姓名、邮箱和密码。

如果网站采用邀请注册，还需要填写管理员提供的邀请码。邀请码只在注册时使用，之后登录不需要再次输入。

### 2.2 登录

访问 `/login`，使用注册邮箱和密码登录。登录成功后会进入项目列表 `/workspace`。

每个账号拥有自己的私有工作区。正常情况下，你看不到其他用户的项目，其他用户也看不到你的项目。

### 2.3 退出登录

在项目列表页面点击“退出登录”。在共享电脑上使用后务必退出，不要只关闭浏览器标签页。

## 3. 管理项目

项目列表支持：

- 新建项目。
- 打开画布。
- 重命名项目。
- 删除项目。
- 查看项目 revision 和更新时间。
- 进入 Skills 页面管理可复用流程。

删除项目属于重要操作，请在确认项目不再需要后执行。项目删除后的恢复能力取决于管理员的存储和备份策略。

## 4. 认识画布

### 4.1 创建节点

在画布空白位置点击鼠标右键打开节点菜单，选择 Video、Image、Audio、Text 或 Storyboard 分类中的工具。选中工具后，在画布上点击希望放置的位置。

如果进入了节点放置状态但不想继续，可点击鼠标右键取消。

### 4.2 移动和连接

- 拖动节点顶部或空白区域移动节点。
- 从节点输出 Handle 拖到下游节点对应颜色的输入 Handle 建立连接。
- 文本、图片、视频和音频使用不同颜色的输入端口。
- VideoNode 会根据所选模型显示其真正支持的输入类型。
- 切换视频模型后，应重新检查已有连接是否仍符合新模型限制。

### 4.3 编辑设置

选中节点后，可以编辑提示词、模型、比例、时长、分辨率、音色或其他参数。不同模型显示的设置不同。

节点上的素材选择器可以决定哪些已连接素材真正参与本次生成，并用 `@1`、`@2` 等编号表示提示词中的参考素材顺序。

### 4.4 运行

- 节点右下角的 Run：运行当前节点。
- 底部“运行选中”：运行当前选中的节点。
- 底部“运行工作流”：按依赖关系运行整张画布。
- 多选后的“运行”：按节点依赖顺序运行选中区域。

运行前确保上游节点已有成功结果。视频等异步任务会先显示等待或运行状态，完成后自动更新预览。

## 5. 上传和使用本地素材

节点菜单支持上传：

- 图片：JPEG、PNG、WebP、GIF。
- 视频：MP4、WebM、MOV、M4V。
- 音频：MP3、WAV、AAC、FLAC、M4A 等浏览器可识别格式。

也可以把剪贴板中的图片、视频或音频直接粘贴到画布。上传素材会先归档到站点配置的 Bunny Storage，再以稳定 URL 提供给下游模型。

注意：模型供应商不一定支持菜单中所有上传格式。上传成功只说明 Mindverse 已保存文件，不代表目标模型一定接受该编码和容器。

## 6. 文本、剧本和分镜

### Prompt / Text

用于保存创意想法、生成描述、整理文本，或者向下游节点传递提示词。

### Script

填写故事概要和风格，生成结构化剧本。

### Storyboard

把剧本或故事拆成分镜。成功后可继续生成分镜图片，并作为图片或视频节点的输入。

推荐先用较少镜头验证风格，再扩展完整流程，避免一次生成大量付费内容。

## 7. 图片节点

图片节点支持文字提示词和参考图片连接。根据模型不同，可选择 GPT Image 2、Nano Banana 或预设的角色转面、九宫格、俯视场景等工作流。

生成后可使用“标注与修改”功能：

1. 在原图上添加箭头、矩形、圆形或文字说明。
2. 填写修改要求。
3. 创建新的修订图片节点。

原图不会被覆盖。建议保留关键版本，避免在同一个节点上反复改写提示词后无法回溯。

## 8. 视频节点通用流程

1. 新建 VideoNode。
2. 在节点底部选择模型。
3. 连接模型所需的文本、图片、视频或音频节点。
4. 在素材选择区确认实际参与生成的素材。
5. 填写提示词。
6. 选择允许的时长、比例或分辨率。
7. 点击 Run。
8. 等待异步任务完成。

模型切换时，输入端口和限制会变化。不要假设所有视频模型都支持相同的图片数量、视频数量、比例或时长。

## 9. minimax_h3

选择 `minimax_h3` 后：

- 提示词最长 7,000 字符。
- 最多选择 2 张参考图片。
- 时长为 5–15 秒。
- 支持 16:9、9:16、1:1。
- 可点击“增强提示词”调用 MiniMax Context IR。

提示词增强会使用当前提示词和最多 2 张已选参考图。增强结果返回后仍可手动修改，再正式生成视频。

## 10. minimax_ref2va

`minimax_ref2va` 是多模态参考视频模型，只支持以下两种模式。

### 10.1 图片 + 音频

连接并选择：

- 1 张图片。
- 1 段音频。

不能多图，也不能同时连接参考视频。

### 10.2 视频参考

连接并选择：

- 1–3 段视频。
- 每段视频必须自带音轨。
- 所有参考视频总时长不超过 15 秒。

视频模式不能再单独连接音频，也不能混入图片。Mindverse 会在提交前使用 ffprobe 检查视频音轨和总时长。

### 10.3 输出设置

- 输出时长：4–15 秒。
- 默认时长：4 秒。
- `audio_flow_shift` 默认 3.0，可在节点设置中调整。
- 输出画面比例由参考图片或参考视频决定。

如果同时连接了图片、音频和视频，请在素材选择器中明确选择其中一种模式，否则系统会阻止提交并显示输入冲突。

## 11. 数字人视频

### 数字人视频 / OmniHuman 1.5

典型输入：

- 1 张清晰的人物图片。
- 1 段语音。

建议：

- 人脸清晰、无遮挡，画面不要过度压缩。
- 音频内容完整、噪音较少。
- 确认你拥有图片和声音的使用授权。
- 先用短音频验证口型和身份一致性，再制作长内容。

OmniHuman 的输出比例由输入图片决定。720p 和 1080p 可能对应不同速度或上游处理模式。

## 12. 视频抽帧与连续生成

视频抽帧是 Video 分类下的独立节点。

### 抽取最后一帧

1. 连接一个已完成的 VideoNode。
2. 新建“视频抽帧”节点。
3. 选择“最后一帧”。
4. 运行节点。

系统会创建一个 Reference 节点，可把它连接到下一个视频节点，形成“上个视频尾帧 → 下个视频首帧”的连续流程。

### 抽取当前画面

1. 打开源视频预览。
2. 把时间轴拖到需要的画面。
3. 关闭预览。
4. 在抽帧节点选择“当前画面”并运行。

VideoNode 会记住播放位置。放大预览中不提供抽帧按钮，以免遮挡画面。

## 13. MiniMax H3 2K 再生成

该节点不是通用视频放大工具，只适用于符合 MiniMax H3 768P 规格的来源。

### 连接源视频模式

- 连接且只连接一个合格的视频到 `base_video`。
- 原提示词可以从连接的 H3 VideoNode 自动继承。
- 如果原任务使用了首帧、尾帧或其他参考媒体，需要重新连接这些素材。

### Source Task ID 模式

- 输入同一 MiniMax 账号下成功的官方任务 ID。
- 账号需要拥有对应白名单权限。
- 任务必须仍在供应商允许的查询时间范围内。

## 14. 音乐、TTS 和人声克隆

### HKGAI Music

填写歌曲名称、标签和段落描述后生成音乐。标签可描述类型、情绪、速度和是否需要人声；实际是否支持特定人声能力取决于当前接口版本。

### HKGAI TTS

可以直接选择内置音色生成语音。如果要使用参考录音音色，通常需要先完成“创建参考声音”，获得 Voice ID，再用该 Voice ID 生成语音。

### Qwen 人声克隆

1. 新建人声克隆节点。
2. 上传清晰的参考录音。
3. 确认已获得声音所有者授权。
4. 创建克隆声音并等待 Voice ID。
5. 将人声克隆节点连接到“克隆人声生成”节点。
6. 输入要朗读的文字并运行。

不要克隆未授权的声音，不要用于冒充、欺诈或误导性内容。

## 15. 视频编辑与 HyperFrames

### Video Edit

可连接一个或多个视频和音频，进行排序、裁剪、淡入淡出、配乐、字幕和转码。先在节点中确认素材顺序，再运行。

### Codex + HyperFrames

适合自然语言描述的复杂后期、标题动画、字幕、网页式动态图形和多段合成。例如：

> 把连接的视频剪成 15 秒竖屏广告，节奏明快，添加简洁字幕和结尾品牌定格。

该流程可能比普通模型任务耗时更长。运行期间不要反复点击 Run，以免产生重复工程或重复任务。

## 16. 多选、移动和批量操作

1. 按住 `Shift`。
2. 在画布空白处按住鼠标左键。
3. 拖动框住目标节点。
4. 松开鼠标完成选择。

橙色虚线框会保留。之后可以：

- 拖动整个选择框，统一移动节点。
- 批量运行。
- 批量删除。
- 清除选择。
- 设置分组颜色或锁定已有分组。

批量运行会按依赖顺序执行，但不会自动修复无效连接或缺失输入。

## 17. Agent 和 Skills

### Agent

可以用自然语言要求 Agent 创建、编辑或整理工作流。建议描述清楚：

- 最终目标。
- 希望使用的素材。
- 输出类型、时长和比例。
- 指定模型或供应商。
- 哪些步骤允许产生费用。

Agent 会根据当前能力目录规划节点，但在运行付费任务前仍应人工检查模型和输入。

### Skills

如果一组节点以后会重复使用，可以把当前画布保存为 Skill。之后从 Skills 页面选择该 Skill，再回到画布放置模板。

不要在 Skill 描述、节点提示词或模板里保存 API Key、密码或私人凭据。

## 18. 保存、草稿和导入导出

### 自动保存

远程项目会自动保存。正常情况下不需要频繁手动点击保存。

如果远程保存失败，系统会尽量把当前修改保存在本浏览器草稿中。浏览器草稿是应急副本，不等于云端已经保存。

看到“远程工作流保存失败”时：

1. 不要立即清除浏览器数据。
2. 检查网络连接。
3. 重新登录，确认会话未过期。
4. 联系管理员检查 Bunny Storage 和数据库。
5. 在恢复前避免同时用多个标签页编辑同一项目。

### JSON 导入导出

顶部工具栏支持导出和导入画布 JSON。JSON 主要保存节点结构和配置，不应被当作所有媒体文件的完整离线备份。导入未知来源 JSON 前应先确认内容安全。

## 19. 常见问题

### 为什么任务一直在等待？

视频任务通常是异步的。供应商可能排队、限流或处理时间较长。等待期间不要连续重复运行；可稍后刷新项目，系统会尝试恢复可识别任务的轮询。

### 为什么提示素材格式错误？

文件扩展名不等于真实编码格式。例如名为 `.mp3` 的文件可能实际是 M4A/AAC。可先用 FFmpeg 转成真实 MP3 或 MP4，再重新上传。

### `reference-audio-1` 是什么？

它通常是 Mindverse 为站内参考音频生成的资产名称，不是网址。若显示 `Failed`，重点检查真实音频容器、编码、供应商限制和资产处理状态。

### 为什么本地注册的账号在 Render 看不到？

只有本地和 Render 连接同一个 Postgres 数据库，并使用同一套 Bunny Storage 时，用户和项目才是同一份数据。不同数据库不会自动同步。

### 为什么修改 Auth Secret 后需要重新登录？

Auth Secret 用于保护会话。修改后旧会话会失效，但账号和项目不会被删除。

### 为什么别人看不到我的项目？

项目按登录账号和 workspace 隔离。这是正常的隐私设计，而不是同步故障。

## 20. 安全与版权注意事项

- 不要在提示词、节点、Skill、截图或聊天中填写 API Key。
- 不要上传没有授权的人脸、声音、音乐、影视素材或商业图片。
- 使用网络搜索素材时，应核查来源页面和发布许可。
- 生成式内容可能存在事实错误、版权风险、人物失真或不合规结果，发布前必须人工审核。
- 视频、图片、音乐和 TTS 可能分别计费；失败任务是否计费由供应商规则决定。
- 涉及真人数字人或声音克隆时，应保存明确授权记录，并对合成内容进行适当标识。
